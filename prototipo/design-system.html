ClickClak — Sistema de diseño (v1)

Base de tokens, átomos y componentes sobre la paleta A · Corporate Trust (decisión confirmada). Fuente única de verdad: tokens.css. Todo color de texto sobre fondo de color en esta página cumple contraste AA (≥ 4.5:1 texto normal, ≥ 3:1 texto grande/ícono) salvo donde se indique.

2. Botones

Un solo botón primario por vista. Estados: normal, hover, focus (anillo visible por teclado), active (scale), disabled. Alto táctil mínimo 44px — aquí 48px.

3. Alertas inline (banner)

Fondo tintado + borde + texto oscuro del mismo hue (no color puro sobre blanco) para pasar AA. Usar para feedback persistente dentro de una pantalla o formulario.

4. Toast (notificación flotante)

Confirmación breve y auto-descartable (3–4s), esquina inferior o superior. Color sólido porque el texto es corto y siempre blanco (contraste ≥ 4.5:1 verificado sobre cada color base).

✔ Asistencia marcada — 08:03 a.m.
✕ Error de red. Reintentando…

5. Popup / modal de confirmación

Overlay --color-overlay (55% opacidad) bloquea el fondo. Acción destructiva siempre a la derecha con color --color-danger; cancelar es secundario. Cierre por ✕, overlay-click y tecla Esc.

¿Cerrar sesión?

Tu turno sigue activo. Si cierras sesión, deberás volver a autenticarte para marcar tu salida.
